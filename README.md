# BWPDIY网页版

## 功能

- 傻瓜式制作百闻牌式神、战斗、法术、形态、幻境与协战六类卡牌，纯前端运行，卡牌数据仅存在于本机浏览器。
- 支持常规卡面的卡图上传、拖动、缩放、旋转、锁定；协战牌，两个式神头像可分别上传并自动裁成菱形。
- 卡牌按官方卡面密度自适应排版、内含[[关键词/灵咒]]高亮、数值图标等语法、可快捷输入语法指令一步到位。
- 稀有度、勾玉、数值角标、派系标与文字描述的位置和大小均可独立调整；
- 常规/琉璃/墨染/百炼四种牌框，卡面 PNG 导出；卡库与项目管理，支持整库 JSON 备份导出与导入。
- 同时，也可以更改亮色主题/暗色主题/跟随系统主题，可调整圆角、动效、部件配色，并支持自定义CSS。
